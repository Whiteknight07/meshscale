# Cloudflare SSH research

Earlier experiments investigated Access for Infrastructure over Mesh. The maintained implementation and limitations are documented in [Cloudflare SSH](../../docs/cloudflare-ssh.md).

Raw owner-account evidence and the environment-specific live probe were removed before public release because they contained personal addresses, device/resource identifiers, and host paths. They were not general integration fixtures. Do not infer current support or authorization guarantees from a historical successful login. Follow the maintained tests and documented acceptance gates instead.
