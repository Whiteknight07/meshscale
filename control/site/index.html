meshscale

Your devices on one private network, on Cloudflare.

meshscale is an open-source CLI and macOS menu bar app for Cloudflare Mesh. It gives Mesh a Tailscale-style workflow: meshscale up, device status, .mesh names, keyless SSH, access rules and Linux exit nodes. Cloudflare's official client carries every packet; meshscale is a thin layer over it.

Get started

curl -fsSLO https://github.com/Whiteknight07/meshscale/releases/latest/download/install.sh
sh install.sh
meshscale up

meshscale up opens "Sign in with Cloudflare", prepares your account, and connects this device. See the install guide for macOS and other options.

What "Sign in with Cloudflare" grants

meshscale asks for the Zero Trust permissions it needs to manage your Mesh: devices, connectors, networks, Access apps and policies, and SSH settings. Tokens stay on your device, in a file only your user can read. meshscale has no server of its own that receives them, and you can revoke access at any time with meshscale logout or from your Cloudflare profile.
