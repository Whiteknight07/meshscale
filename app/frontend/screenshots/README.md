# Reference screenshots

Only signed-out/sign-in snapshots are retained. Account-bearing screenshots and the stale verification manifest were removed for public release because the fixtures displayed an email on a real mail domain. See [removed artifacts](../../../docs/release/removed-artifacts.md) for the full list.

Before generating replacements, change fixtures to reserved `example.com` identities and clearly synthetic network data. Inspect each image and comparison sheet before committing; do not export a live account. See [the frontend README](../README.md) and [Mac screenshot policy](../../../macos/screenshots/README.md).
