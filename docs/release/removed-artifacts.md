# Artifacts removed for public release

The S1 privacy review removed the following tracked artifacts. Raw logs/inventories exposed account, resource, device, endpoint, or local-machine details; packet captures cannot be reliably sanitized as text. Host-specific mutation scripts depended on developer infrastructure. Account-bearing screenshot fixtures used a non-reserved mail domain, so they were removed rather than edited. Signed-out/sign-in snapshots were visually reviewed and retained.

The generic design guidance referenced a missing `LICENSE.txt` and had no verifiable redistribution attribution; it was removed rather than silently relicensed under MIT. Reintroducing it requires provenance and applicable license terms.

Deletion does not remove history. See [history-audit.md](history-audit.md). Maintained source and user-facing guides remain the source of behavior claims. Historical measurements are labeled as observations; removed raw evidence is not a current public reproducibility artifact.
