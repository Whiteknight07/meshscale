# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) by reference, including its standards, scope, and enforcement guidelines. The reporting procedure below replaces its contact placeholder.

Participation should be welcoming and free from harassment or discrimination. Treat people respectfully, give constructive feedback, and protect others' personal information. These expectations apply in project spaces and when representing the project elsewhere.

Report conduct concerns using GitHub's **Report content** control on the relevant issue, comment, or pull request; choose **Report to repository admins** where available. Use GitHub's private abuse-reporting route when a public discussion would expose personal information or when the concern involves a repository administrator. Do not post private incident details in an issue. Security vulnerabilities use the separate [private security process](SECURITY.md).

Maintainers will handle reports confidentially as far as practical, consider evidence fairly, and apply proportionate correction, warning, temporary restriction, or permanent exclusion under the Covenant's enforcement guidelines. They may remove content or contributions that violate these standards. Retaliation against reporters is unacceptable.

Attribution: Contributor Covenant 2.1, maintained by the Organization for Ethical Source. Its enforcement framework draws on Mozilla's community guidelines. The linked original governs the adopted standards; these paragraphs describe the project's local reporting and moderation procedure.
